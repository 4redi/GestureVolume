# Control Volume by gesture

This is a computer vision project, built in python for controlling your computer's volume using your fingers.
Built completely in python and using different CV libraries.

> For the app to work, python 3.11.x must be installed

## Clone the repo

```bash
git clone https://github.com/4redi/GestureVolume
```

## Open the project in the terminal and create a new environment

```bash
cd GestureVolume
```

## Create the environment for python 3.11.x version

```bash
py -3.11 -m venv myenv
```

## Activate the environment (I'm using powershell for this example)

```bash
myenv\Scripts\Activate.ps1
```

## Install dependencies

```bash
pip install -r requirements.txt
```

## Open in your IDE/Code editor and run the code

```bash
python main.py
```
